## About me

I'm Vishal, a senior full stack developer who likes the work behind the work: the decisions that make a product calm, quick, and ready for its next chapter.

My home base is React, Next.js, Node.js, and TypeScript. I've used them to build booking engines, commerce platforms, logistics tools, and AI-assisted dashboards. I enjoy owning the whole product surface, from shaping interfaces and designing API boundaries to modelling data and improving performance, and leaving teams with a foundation they can extend confidently.

### How I work

|        | Principle         |                                                                                                                 |
| :----: | ----------------- | --------------------------------------------------------------------------------------------------------------- |
| **01** | **Make it clear** | Good software explains itself. I turn dense requirements into interfaces and APIs people can reason about.      |
| **02** | **Make it fast**  | Performance is part of the product. I care about the first paint, the last query, and every moment between.     |
| **03** | **Make it last**  | A clean foundation gives a team room to move. I build modular systems that can grow without losing their shape. |

### What I bring

- Product-minded decisions
- Full-stack ownership, from interface to data layer
- Motion with purpose
- Kind, direct collaboration
