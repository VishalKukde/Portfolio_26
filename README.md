## Architecture

This is a single-page Next.js App Router application. The code is organized by responsibility so content updates do not require rewriting presentation components.

```text
src/
|-- app/
|   |-- globals.css       # Design tokens, responsive styles, motion and scrollbar
|   |-- icon.svg          # Custom VK favicon
|   |-- layout.tsx        # Root metadata and smooth-scroll boundary
|   `-- page.tsx          # Portfolio composition
|-- components/
|   |-- Background.tsx    # Site grid and ambient background layers
|   |-- LoadingScreen.tsx  # Branded 2-second loading sequence
|   |-- ProjectStack.tsx   # GSAP project card stacking behavior
|   `-- SmoothScroll.tsx   # Lenis and ScrollTrigger integration
|-- constants/
|   `-- index.ts          # Navigation, social links, email and hero switch
|-- data/
|   |-- experience.ts      # Work history and highlights
|   |-- projects.ts        # Project content, URLs, images and stacks
|   `-- skills.ts          # Skill categories and proficiency data
|-- lib/
|   `-- scroll.ts          # Clean internal section navigation
`-- sections/
    |-- About.tsx
    |-- Contact.tsx
    |-- Experience.tsx
    |-- Footer.tsx
    |-- Hero.tsx            # Hero V1: terminal-style layout
    |-- HeroV2.tsx          # Hero V2: editorial split-panel layout
    |-- Navbar.tsx
    |-- Projects.tsx
    `-- Skills.tsx

public/
`-- Image/                 # Local project preview images
```

## Getting Started

### Requirements

- Node.js 18.17 or newer
- npm 9 or newer
- A modern browser with JavaScript enabled

### Installation

```bash
git clone <your-repository-url>
cd <repository-directory>
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local Next.js development server. |
| `npm run lint` | Run Next.js ESLint checks. |
| `npm run build` | Create an optimized production build. |
| `npm run start` | Start the production server after building. |

## Customization Guide

### Update personal information

Edit [`src/constants/index.ts`](src/constants/index.ts) to update:

- Navigation labels and section targets
- GitHub and LinkedIn URLs
- Contact email
- Active hero version

### Switch between Hero versions

Both hero designs are kept in the project. Change one value in `src/constants/index.ts`:

```ts
export const HERO_VERSION: "v1" | "v2" = "v1";
```

Use `"v1"` for the original terminal-style hero or `"v2"` for the editorial split-panel hero.

### Update portfolio content

- Projects: [`src/data/projects.ts`](src/data/projects.ts)
- Skills: [`src/data/skills.ts`](src/data/skills.ts)
- Experience: [`src/data/experience.ts`](src/data/experience.ts)
- Project images: [`public/Image`](public/Image)

Each project supports a live URL, local preview image, fallback image, technology list, highlights, and mobile viewing guidance.

### Update the visual system

The main design tokens are declared at the top of [`src/app/globals.css`](src/app/globals.css):

| Token | Value | Usage |
| --- | --- | --- |
| `--ink` | `#14201d` | Primary dark surface and text |
| `--ink-soft` | `#20302a` | Secondary dark surface |
| `--paper` | `#f1eee6` | Main page background |
| `--paper-deep` | `#e4e4d9` | Secondary light surface |
| `--lime` | `#c8f169` | Primary action and accent |
| `--coral` | `#ff765f` | Secondary accent and status color |
| `--teal` | `#8ce5d1` | Supporting accent |
| `--moss` | `#64776c` | Muted text |

## Deployment

The app is ready for deployment on Vercel or any platform that supports Next.js.

```bash
npm run build
npm run start
```

For Vercel:

1. Import the repository into Vercel.
2. Keep the framework preset as **Next.js**.
3. Use `npm run build` as the build command if it is not detected automatically.
4. Deploy. No environment variables are required by the current portfolio implementation.

## Accessibility and Performance Notes

- Uses semantic sections, navigation landmarks, labels, and descriptive image alt text.
- Includes reduced-motion handling for users who prefer less animation.
- Uses `next/image` for project previews.
- Uses responsive layouts and mobile navigation.
- Keeps project animation and ScrollTrigger behavior inside client-only components.
- Uses local fallback image URLs when a project preview image cannot load.
